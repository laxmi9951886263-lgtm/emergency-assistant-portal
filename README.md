# Emergency Assistant Portal

Angular 20 project built to cover the Essentials of Web Programming syllabus (HTML, CSS, JavaScript, XML/AJAX, TypeScript, Angular).

## Run it
```bash
npm install
npm run api     # terminal 1: json-server on http://localhost:3000 (stores help requests in db.json)
npm start       # terminal 2: Angular on http://localhost:4200
```
If the API is not running, requests are saved in the browser (localStorage) instead.

## Optional media
Add `src/assets/media/cpr-demo.mp4` and `src/assets/media/metronome-110bpm.mp3` for the video and audio players on the First aid page.
